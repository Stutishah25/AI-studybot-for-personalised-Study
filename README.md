# 🧠 NOVA — Personal AI Study Companion

> **Understand faster. Remember longer. Study smarter.**

NOVA is a personalized AI-powered study companion designed to help students learn more effectively.

Unlike a traditional AI chatbot that simply answers questions, NOVA analyzes a student's **subjects, syllabus, learning preferences, study history, weak topics, and upcoming exams** to create a personalized learning experience.

It transforms any topic into **structured notes, interactive mind maps, memory shortcuts, adaptive quizzes, revision plans, and targeted learning sessions.**

---

## 🚀 Why NOVA?

Most AI study tools focus on answering:

> "What is this concept?"

NOVA focuses on the bigger question:

> **"What should I learn, how should I learn it, and what should I revise next?"**

NOVA creates a continuous learning loop:

```text
        Learn
          ↓
       Practice
          ↓
        Recall
          ↓
      Evaluate
          ↓
   Detect Weakness
          ↓
   Personalized Revision
          ↓
        Mastery
